# Portfolio Summary

## Project
**Multi-Source SOC Investigation: Web & SSH Attack Correlation**

## CV version
Investigated real malicious activity by correlating Wazuh SIEM alerts, Linux SSH authentication logs, Cloudflare WAF telemetry and threat intelligence, producing a MITRE ATT&CK-mapped incident report and containment recommendations.

## Portfolio version
Built a real-world SOC investigation from live security telemetry, starting with a Wazuh SSH authentication alert and expanding into cross-source correlation across Linux, Cloudflare, threat intelligence and firewall controls. Validated repeated password-guessing activity, assessed a related web-layer probe, mapped evidence to MITRE ATT&CK, documented uncertainty and implemented containment.

## Interview story
**Situation:** Wazuh identified repeated SSH authentication failures against a privileged account.

**Task:** Determine whether the activity was isolated or part of broader reconnaissance.

**Action:** Reviewed raw authentication logs, built a timeline, enriched indicators with threat intelligence, investigated Cloudflare events, compared related network indicators and mapped confirmed behaviour to MITRE ATT&CK.

**Result:** Confirmed repeated malicious SSH password-guessing attempts with no identified successful authentication in the reviewed evidence, correlated separate web-layer probing, applied firewall containment and produced a professional incident report.
